📖 자주 묻는 질문 (FAQ)

세콤달.콤 주식맛집 사용 중 궁금한 점에 대한 답변을 정리했습니다. 추가 문의는 Contact 페이지로 보내주세요.

📊 데이터 관련

데이터는 얼마나 자주 갱신되나요?

주식 시세(OHLCV)는 매 거래일 장 마감(15:30 KST) 후 약 10분 이내에 자동 갱신됩니다. 외국인·기관·개인 수급은 마감 후 30분 이내에 반영되며, 주말·공휴일에는 갱신이 없습니다. 그룹사 관계도와 대주주 정보 같은 DART 기반 데이터는 매월 1회 업데이트됩니다.

실시간 시세를 볼 수 있나요?

본 사이트는 의도적으로 실시간 시세를 제공하지 않습니다. 일·주·월 단위의 거시적 흐름을 전종목 단위로 비교·학습하는 데 특화되어 있으며, 실시간 시세가 필요하시면 증권사 HTS·MTS 또는 한국거래소 공식 서비스를 이용해 주세요.

데이터 정확도는 어느 정도인가요?

모든 원본 데이터는 한국거래소 공시(FinanceDataReader 경유), Naver Finance, 금융감독원 DART 에서 가져옵니다. 자동 수집 후 결측치·이상치 검사를 거치지만, 데이터 처리 과정에서 오류가 있을 수 있습니다. 중요한 의사결정 시에는 반드시 공식 출처에서 재확인하시기 바랍니다.

데이터가 갱신 안 되는 것 같은데요?

헤더의 "최신 데이터" 날짜를 확인해 주세요. 평일 16시 이후에도 전날 날짜로 표시되면 일시적인 배치 지연일 수 있습니다. 1일 이상 갱신이 누락된 경우 Contact 페이지로 알려주시면 즉시 확인해 드립니다.

상장폐지된 종목도 보이나요?

상장폐지된 종목은 자동으로 목록에서 제외됩니다. 일시적 거래정지(VI 발동, 관리종목 지정 등)는 표시되지만, 거래정지 기간 동안은 차트가 평탄하게 유지됩니다.

🔐 회원·계정

회원 가입은 어떻게 하나요?

헤더 우측의 "카카오로 시작하기" 버튼을 누르시면 별도 이메일·비밀번호 입력 없이 카카오 계정으로 몇 초 만에 가입이 완료됩니다. 가입 후 관심종목 저장 등 회원 전용 기능을 사용할 수 있습니다.

비회원으로도 모든 기능을 사용할 수 있나요?

차트 보기·검색·필터·블로그 읽기 등 핵심 기능은 비로그인 상태에서도 모두 사용 가능합니다. 다만 관심종목 저장·기기 간 동기화는 카카오 로그인이 필요합니다.

회원 탈퇴는 어떻게 하나요?

로그인 후 헤더의 닉네임 메뉴에서 "회원 탈퇴" 를 선택하시면 즉시 탈퇴되며, 저장된 관심종목·테마 설정 등 모든 개인정보가 삭제됩니다. 자세한 내용은 개인정보처리방침을 참고하세요.

관심종목은 몇 개까지 저장 가능한가요?

현재는 사용자 1인당 무제한 저장 가능합니다. 차후 운영 부하에 따라 제한이 생길 수 있으나, 합리적 범위 (수백 종목)에서는 자유롭게 사용하실 수 있습니다.

📱 사용 환경

모바일에서도 잘 보이나요?

모든 페이지가 모바일 반응형으로 설계돼 있습니다. 다만 차트 비교 기능의 특성상 큰 화면(태블릿·데스크톱) 에서 사용하는 것이 더 편리합니다. 작은 화면에서는 카드 레이아웃이 자동으로 한 줄씩으로 축약됩니다.

테마(다크/라이트)를 변경할 수 있나요?

헤더 우측의 ☀ 아이콘을 클릭하면 다크/라이트/크림/그레이 4가지 테마를 순환합니다. 선택한 테마는 브라우저에 자동 저장되며, 카카오 로그인 시 기기 간에도 동기화됩니다.

키보드 단축키가 있나요?

차트 페이지에서 검색창에 포커스가 있을 때 Enter 로 첫 검색 결과 선택, ESC 로 모달 닫기, ↑↓ 화살표로 검색 결과 간 이동이 가능합니다. 추가 단축키는 사용자 의견을 받아 점진 추가 예정입니다.

💰 광고·정책

왜 광고가 표시되나요?

본 사이트는 무료로 운영되며, 서버·CDN·도메인 등 운영비를 충당하기 위해 Google AdSense 광고가 헤더 직하단의 작은 영역에 표시될 수 있습니다. 페이지 본문이나 차트 위에 직접 광고를 삽입하지 않으며, 사용자 경험을 해치는 형태의 광고는 의도적으로 피합니다.

유료 서비스 계획이 있나요?

향후 일부 고급 기능(맞춤 알림, 고급 스캐너, API 접근 등)은 선택적 유료 구독으로 제공될 예정입니다. 현재 무료 기능은 그대로 유지되며, 유료 전환은 원하시는 분에게만 별도 안내됩니다.

광고 차단(AdBlock)을 써도 되나요?

광고 차단을 사용해도 사이트의 모든 기능은 정상 작동합니다. 다만 운영 지속을 위해 가능하면 secomdal.com 도메인은 광고 차단 예외로 등록해 주시면 감사하겠습니다.

⚖️ 기타

투자 자문이나 종목 추천을 받을 수 있나요?

본 사이트는 데이터 시각화 도구이며, 투자 자문이나 종목 추천을 제공하지 않습니다. 정기 발행되는 일일 분석 글도 데이터 + 뉴스 기반의 객관적 관찰일 뿐 매수/매도 권유가 아닙니다. 투자 판단의 모든 책임은 이용자 본인에게 있습니다.

데이터를 외부 사이트나 앱에 사용해도 되나요?

본 사이트가 가공해 표시하는 데이터는 원본 데이터의 가공물이며, 상업적 재배포는 권장하지 않습니다. 개인 학습·연구 목적의 사용이나 출처 표기를 통한 인용은 자유롭게 가능합니다. 대량 자동 수집(스크래핑)은 삼가해 주시고, 비슷한 데이터가 필요하시면 원본 출처(한국거래소·DART·Naver)를 직접 사용하시는 것을 권장합니다.

버그를 발견했어요. 어떻게 신고하나요?

Contact 페이지의 의견 폼으로 보내주시거나 my.lunanstar@gmail.com 으로 직접 메일 주시면 빠르게 확인해 조치하겠습니다. 화면 캡처나 재현 단계가 있으면 더 빠른 해결에 도움이 됩니다.

기능 추가 제안은 받으시나요?

네, 적극 환영합니다. Contact 페이지로 제안 보내주시면 검토 후 블로그에서 채택 여부와 일정을 안내합니다. 사용자 의견에서 출발한 기능이 다수 구현돼 있습니다.
