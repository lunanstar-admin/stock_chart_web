Dart공시분석 — 개인정보 처리방침

최종 업데이트: 2026-05-16 · iOS App · Bundle ID com.kimkihong.DartReader

1. 개요

「Dart공시분석」(이하 "본 앱")은 금융감독원 전자공시시스템(DART)의 공개 공시 데이터를 검색·분석·요약하여 제공하는 단순 정보 서비스입니다. 본 앱은 사용자에 대한 회원 가입을 요구하지 않으며, 광고 추적·마케팅 목적의 개인정보를 수집하지 않습니다.

2. 수집하는 정보

항목수집 시점이용 목적보유 기간
APNs 디바이스 토큰
(개인 식별 불가)		 사용자가 푸시 알림 권한을 허용한 시점 분기보고서·반기보고서 등 신규 공시 발생 시 푸시 알림 발송 앱 삭제 또는 토큰 만료 시 자동 폐기 (최대 1년)
광고 식별자(IDFA)
(ATT 권한 허용 시에만)		 앱 첫 실행 시 Apple ATT 권한 요청 → 사용자가 "허용"한 경우 Google AdMob 맞춤형 광고 노출. 거부 시 비맞춤 광고로 대체 iOS 시스템 → 설정 → 일반 → 추적에서 언제든 철회 가능
앱 설정
(테마, API URL 등)		 사용자가 설정 변경 시 다음 실행 시 동일 환경 유지 디바이스 내 UserDefaults — 외부 전송 없음

3. 수집하지 않는 정보

  • 이름, 이메일, 전화번호, 주소 등 직접 식별 정보
  • 위치 정보 (GPS, IP 기반 위치 모두)
  • 연락처, 사진, 캘린더 등 디바이스 데이터
  • 금융 계좌 정보, 거래 내역 (본 앱은 매매 기능 없음)

3-1. 광고 안내

본 앱은 Google AdMob 전면 광고(Interstitial)를 포함합니다. 공시 상세 화면 3회 진입마다 1회 광고가 표시됩니다.

  • 맞춤형 광고: 앱 첫 실행 시 Apple ATT(App Tracking Transparency) 권한을 요청합니다. 허용 시 Google이 IDFA를 사용해 관심사 기반 광고를 표시합니다.
  • 비맞춤 광고: ATT를 거부해도 광고는 정상 노출되며, 일반 광고로 대체됩니다. 앱의 모든 기능은 동일하게 이용 가능합니다.
  • 광고 사업자: Google LLC. 자세한 데이터 처리는 Google 개인정보처리방침 참조

4. 제3자 제공 및 위탁

본 앱은 수집한 정보를 제3자에게 판매·공유·제공하지 않습니다. 다음 외부 서비스의 공개 데이터만 사용합니다:

  • 금융감독원 전자공시시스템(DART OpenAPI) — 공시 데이터 조회 (사용자 정보 전송 없음)
  • Anthropic Claude API — 공시 본문의 AI 요약 생성 (공시 원문만 전송, 사용자 정보 없음)
  • Apple Push Notification service (APNs) — 디바이스 토큰으로만 푸시 발송

5. 사용자의 권리

  • 알림 거부: iOS 시스템 설정 → 알림 → Dart공시분석 에서 언제든 해제
  • 데이터 삭제: 앱을 삭제하면 디바이스 토큰은 자동으로 무효화되며 더 이상 알림이 발송되지 않음
  • 문의·열람 요청: 아래 이메일로 요청 시 30일 이내 응답

6. 데이터 보호 조치

  • 모든 통신은 HTTPS/TLS 1.2 이상으로 암호화됩니다 (App Transport Security 준수)
  • 서버는 KIS·DART 키 등 운영 시크릿을 환경변수로 격리 보관합니다
  • 디바이스 토큰은 운영자만 접근 가능한 서버 SQLite에 저장됩니다

7. 면책

본 앱이 제공하는 모든 공시 요약·호재/악재 분류·AI 밸류에이션 논평·주가 영향 데이터는 공개 정보(DART OpenAPI)를 기계적으로 가공한 단순 참고자료입니다. 특정 종목의 매수·매도 추천이 아니며, 투자에 따른 손익은 전적으로 투자자 본인의 책임입니다.

8. 변경 사항

본 방침은 법령 변경 또는 서비스 변경 시 갱신될 수 있으며, 변경 시 본 페이지 상단의 업데이트 날짜를 통해 고지합니다.
